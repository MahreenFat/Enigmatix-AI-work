Mobile Connect

To use from your phone, open this file from a local server and navigate to the same IP address on your mobile browser.

  • Install Live Server or run a local HTTP server.
  • Use a phone on the same Wi-Fi network.
  • Open http://YOUR-PC-IP:8000 or the port your server uses.

Tip: Keep the page open on mobile, make sure the phone volume is on, and tap the sound button before setting the alarm.
